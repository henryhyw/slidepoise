# Public PwC and Strategy& references

This profile contains 36 indexed pages from four publicly published documents. It supports per-slide retrieval by communication purpose, layout and information relationships.

The complete 30-page Strategy& publication provides the primary consulting-deck reference. Selected pages from three PwC publications add operating-model, architecture and ecosystem examples. Cover pages, dividers, contact pages and dense report pages remain available for context and are excluded from default analytical-slide retrieval.

The source PDFs are in `source-documents/`. Page previews and their searchable provenance are in `libraries/visual_references/catalog.json`. Each entry records its source page, observed structure and file hashes. Descriptive index titles and composition notes are editorial metadata authored for retrieval.

## Use the references

After running SlidePoise setup, select the `pwc-public` profile for a run. The Agent retrieves candidates for each slide, inspects the actual pages and selects relevant references. A high search rank is a browsing aid. It does not establish design suitability.

Use the [reference retrieval workflow](../../slidepoise/references/reference-retrieval.md) to query from slide intent or include this catalog alongside another client profile. Apply the client's colours and identity to the new work. Source claims, figures and logos stay with their original publication unless separately supported and selected.
