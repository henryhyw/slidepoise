The editorial folio normalization and consulting inherited frame were intentional. Canonical icon identity is also intentional. These exceptions do not excuse changes in unrelated hierarchy, cell alignment or semantic connections.

The consulting slide 3 review claimed that both return paths were visible. Slide 5's review claimed that Adoption remained one word. Both claims contradicted the current renders. Matching hashes did not make those observations true.

## Changes to the production method

The host retains content obligations independently of the semantic map. Construction checks the declared entities and relationship endpoints against those obligations. The host must still inspect the plan and image to establish complete coverage.

Native table cells can specify pixel margins without accidentally sending them to Office as points. Cell formatting remains explicit, including rich text, alignment and selected-row treatment. The host compares real wrapping after rendering.

Current semantic maps are the reconstruction inputs. The blanket consulting map writer was removed because rerunning it could overwrite page-specific corrections. Scripts containing fixed accepted-review statements were removed. Frozen review records remain historical evidence and must be replaced through actual inspection when their inputs change.

Successful reproduction establishes that a set of inputs yields the same output in a recorded environment. It does not establish that the output is faithful or well designed. The host compares each region and documents unresolved differences before release.

The rendered-table collector was run against the published PDF before replacement. It localized `Adoptio n` and `Downsid e` to the two affected sensitivity-table cells. It reported neither defect in the revised deck. This comparison uses real rendered text within cell coordinates, independently of the constructor's declared font settings.

## Final visual review

The host and an independent reviewer inspected all ten revised pairs and assembled pages. The earlier material and important findings were resolved. Consulting 3 now retains both feedback relationships with clear directional heads. Consulting 5 renders Adoption and Downside intact and keeps the four factor captions separate. Consulting 2 preserves the first data label's orange emphasis and the selected research row.

Small native differences remain explicit. Consulting 1 wraps the final rationale onto two lines. Consulting 4 uses left-aligned week headers and a two-line final gate caption. Its sequence ends at G4, as specified by the plan. Editorial text retains modest font-metric differences, and the closing headline uses Georgia to approximate the source's weight and proportions. The artwork is preserved.

The updated maps, actual renders, measurements, and new host observations are retained together. The old map writers and fixed acceptance writers are removed. Current handoffs no longer accumulate descriptions of obsolete geometry. The generic example rebuild and comparison commands can reproduce the frozen inputs without issuing a visual verdict.

## Code cleanup

Fifteen obsolete writers were removed. They included scripts that overwrote corrected maps, reset asset selection, restored archived typography over current inputs, and wrote fixed acceptance statements. Two verifiers tied to private output paths were replaced by one parameterized reconstruction comparison command. Earlier artifacts remain evidence, while current maps and handoffs are the active inputs.

The independent code review also found three gaps in the new checks. A required connector could be marked as caption-owned and never emitted. A PDF comparison could use slide filenames instead of the presentation's actual order. Pixel margins could miss the transform from source-image coordinates into slide coordinates. Regression tests now cover all three. Legacy Office-point margins remain supported to preserve valid existing inputs.
